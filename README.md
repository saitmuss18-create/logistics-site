# Auction Car Search Bot

Telegram бот для поиска реальных лотов на **Copart**, **IAAI**, **BidCars**.

## Особенности

- Медленный поиск (1–3 часа) для обхода блокировок
- Случайные задержки 20–90 секунд между запросами
- Ротация User-Agent при каждой итерации
- Точный поиск по критериям (марка, модель, год, цена)
- Дедупликация — один лот приходит только один раз
- Поддержка трёх источников: Copart, IAAI, BidCars

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Заполните TELEGRAM_BOT_TOKEN в .env
python bot.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы |
| `/search BMW 5 2018-2022 до 15000` | Начать поиск |
| `/stop` | Остановить поиск |
| `/status` | Статус и количество найденных лотов |

## Примеры поиска

```
/search BMW 5 series 2018-2022 до 12000
/search Toyota Camry от 5000 до 15000
/search Mercedes E класс 2019-2021
/search Audi A6 2017
```

## Как работает анти-блокировка

1. Перед каждым запросом — пауза **20–90 секунд**
2. Между сайтами — пауза **30–90 секунд**
3. Между итерациями — пауза **5–15 минут**
4. Каждая итерация создаёт новую сессию с новым User-Agent
5. Порядок обхода сайтов перемешивается случайно
